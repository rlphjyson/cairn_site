Template documentation

Every Cairn template is its own Flutter package with its own assets, tests and a tutorial. Pick one to learn how to install it, change the content, theme it, connect a real backend and migrate.

  • MobileE-commerceStorefront, product pages, cart with promo codes, a four-step checkout and order history.
  • WebDashboardKPIs, area, bar, line, donut and radial charts, and a sortable orders table.
  • WebBlogFeatured post, search, categories, pagination, rich posts and a newsletter form.
  • WebDocumentationSidebar, versions, command-palette search, an on-this-page rail and typed content blocks.
  • WebSaaS landingHero, features, testimonials, monthly/yearly pricing, FAQ and a waitlist.
